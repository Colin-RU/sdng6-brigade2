# ЦДНГ-6 · Бригада №2

Атлас Фёдоровского месторождения: 32 куста, 489 записей скважин, поиск, карта, маршруты, избранное и заметки. В настройках доступны светлая и тёмная темы.

## Android

[Скачать приложение для Android](https://github.com/Colin-RU/sdng6-brigade2/releases/latest/download/brigade2-android.apk)

Скачайте APK и откройте его на телефоне с Android 8 или новее. Если телефон запросит разрешение на установку из этого источника, разрешите установку. Атлас готов к работе без интернета сразу после установки.

## iPhone

[Открыть атлас](https://sdng6-brigade2-field-atlas.vasyiliy.chatgpt.site/)

Откройте ссылку в Safari. Нажмите «Поделиться» → «На экран Домой», затем откройте атлас с появившегося значка. При первом запуске с интернетом дождитесь отметки «Доступен без сети». В настройках можно проверить готовность к работе без связи.

## Поиск и маршрут

Введите номер куста в поиск и выберите «Маршрут». Разрешите доступ к точному местоположению и включите геолокацию телефона. Маршрут строится от вашего текущего положения. На открытом месте GPS обычно определяется лучше.

GPS и маршруты работают внутри сохранённого района. Координаты сопоставлены по рабочей схеме и картам; это не результаты полевой съёмки. Состояние проездов и шлагбаумов не обновляется автоматически.

Избранное, заметки и добавленные точки сохраняются на вашем устройстве. Перед удалением приложения сохраните резервную копию через настройки.
