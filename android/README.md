# Android

APK содержит весь атлас, карту, дороги и расчёт маршрутов. Интернет для запуска, поиска и GPS не требуется. Местоположение доступно при открытом приложении; включите геолокацию телефона и разрешите точное местоположение. Первый спутниковый сигнал на открытом месте может определяться до минуты. В разделе «Загруженные карты» можно проверить сохранённую карту.

Чат, общие записи, фотографии, отметки отбора проб и календарь бригады обновляются при подключении к интернету. Чтобы узнавать о новых сообщениях и ответах коллег на экране телефона, войдите с отметкой «Запомнить меня» и включите уведомления в приложении. Android запрашивает разрешение на уведомления отдельно.

После подключения push новые сообщения и ответы доставляются через Firebase Cloud Messaging при наличии интернета и Google Play services, в том числе при закрытом окне приложения. Статус «Уведомления подключены» появляется после регистрации телефона на сервере; «Доставка подтверждена» — после первого успешного получения. Android и ограничения сети могут задерживать доставку. После принудительной остановки приложения откройте его снова.

Пока push не подключены, резервная проверка планируется примерно раз в 15 минут. После успешного подключения периодическая проверка отключается. Общие сообщения и ответы остаются в приложении независимо от системного уведомления. Выход из профиля удаляет привязку уведомлений и локальный токен сеанса. Через 30 дней либо после окончания сеанса потребуется войти заново.

В системных настройках Android доступны две категории: «Чат бригады» и «Кусты и скважины». Их звук, вибрацию и показ можно настроить отдельно. Настройки существующей категории рабочих объектов сохраняются при обновлении приложения.

Сборка на Windows: `pwsh -File android/build-release.ps1`. Скрипт сначала заново копирует текущую папку `dist` в Android assets, затем собирает, подписывает и проверяет APK. Исходная папка `dist` не меняется.

Зависимости для этого скрипта хранятся отдельно, по умолчанию в `D:\sites\android-build-tools`: JDK 17 в `jdk17/<jdk-directory>`, Gradle 8.11.1 в `gradle-8.11.1`, Android SDK в `sdk` с `platforms;android-35` и `build-tools;35.0.0`. Прямые зависимости проекта: AGP 8.9.3, AndroidX WebKit 1.12.1, Core 1.15.0, WorkManager 2.10.1 и Firebase Messaging 26.0.2. Альтернатива — открыть папку `android` в Android Studio и сначала выполнить `prepare-assets.ps1`.

Для release требуется настоящий `android/firebase.properties` с публичными значениями `appId`, `apiKey`, `projectId`, `senderId` именно Android-приложения `ru.brigade2.atlas`. Инициализация использует `FirebaseOptions`, без Google services Gradle plugin. Без конфигурации release останавливается; debug продолжает работать с резервной проверкой. Серверный service-account key никогда не включается в APK.

FCM передаёт только непрозрачный идентификатор уведомления. Текст запрашивается через API с зашифрованным сеансом текущего профиля и проверкой адресата. На высокоприоритетное FCM-сообщение назначается одно ускоренное задание WorkManager; постоянного foreground-сервиса и частого опроса нет. До Android 12 WorkManager может показать короткое служебное уведомление только на время получения записи. Идентификатор установки и секрет смены привязки хранятся зашифрованными Android Keystore отдельно от удаляемого при выходе сеанса.

Постоянный ключ обновлений и зашифрованный Windows DPAPI пароль хранятся отдельно, по умолчанию в `D:\sites\sdng6-brigade2-signing`. Они не входят в репозиторий. DPAPI привязан к текущей учётной записи Windows. Сохраняйте резервную копию ключа и доступного пароля для будущих обновлений; не публикуйте их. Скрипт берёт пароль из окружения процесса, а не аргументов командной строки.

GPS-адаптер Android заменяет стандартный `navigator.geolocation` на приём данных от системного `LocationManager.GPS_PROVIDER`. Параллельные разовые запросы и подписки независимы. Для импорта, экспорта и выбора до трёх фотографий используются системные окна. Встроенный WebView загружает упакованные assets и обращается к разрешённому адресу API бригады; внешние ссылки открываются в браузере и не получают доступ к Android bridge.

Для фоновых уведомлений сохраняется только токен сеанса в зашифрованном виде AES-GCM с ключом Android Keystore; пароль Android-часть не сохраняет. Выход удаляет токен, отменяет задания WorkManager и показанные уведомления. Повторные ответы отсекаются по сохранённым идентификаторам. Android API ограничен конкретным HTTPS-адресом, переходы HTTP не допускаются.
