# Атлас для Android

Требуется Android 8 или новее.

[Скачать APK](https://github.com/Colin-RU/sdng6-brigade2/releases/latest/download/brigade2-android.apk), открыть файл на телефоне и установить приложение. При запросе телефона разрешите установку из выбранного источника.

Атлас работает без интернета сразу после установки. Для маршрута введите номер куста, выберите «Маршрут», включите геолокацию и разрешите точное местоположение.

GPS и маршруты доступны внутри сохранённого района. Координаты получены сопоставлением схемы с картами, без полевой съёмки. Состояние проездов и шлагбаумов не обновляется автоматически.

Заметки и избранное хранятся на телефоне. Перед удалением приложения экспортируйте резервную копию через настройки.
